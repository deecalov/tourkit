Developer experience

From install to your first tour in under a minute.

A clean, typed API with no magic. The configuration reads like a script, events are predictable, and imports work the same in ESM, CJS and the browser.

  • TypeScript-firstStrict options, steps and typed events.
  • Five entry pointsCore, hints, locales, style injector and the migration adapter.
  • CSS custom propertiesThe TourKit theme blends naturally into your design system.
Read the documentation 
import { createTour } from "sitetourkit";
import "sitetourkit/styles.css";

const tour = createTour({
  progress: true,
  steps: [
    {
      title: "Welcome",
      content: "Let's take a quick look around.",
    },
    {
      target: "#analytics",
      title: "Live analytics",
      content: "All the key metrics live here.",
      placement: "bottom-start",
    },
  ],
});

tour.on("complete", ({ reason }) => {
  analytics.track("tour_completed", { reason });
});

await tour.start();
